# 🤖 Crypto Signal Bot

ربات تحلیلگر نهادی ارز دیجیتال با قابلیت تشخیص خودکار از روی عکس

## ✨ ویژگی‌ها

- 📸 تشخیص خودکار از روی عکس چارت
- 📊 تحلیل ۱۸+ اندیکاتور تکنیکال
- 🧠 تحلیل ساختار بازار (Market Structure)
- ⚡ پیشنهاد اهرم هوشمند
- 📈 بک‌تست و ارزیابی عملکرد
- 💎 سیستم اشتراک مادام‌العمر
- 🚀 کاملاً رایگان روی Render

## 📋 پیش‌نیازها

- توکن ربات تلگرام (از @BotFather)
- کانال تلگرام خصوصی
- حساب گیت‌هاب
- حساب Render

## 🚀 راه‌اندازی سریع

1. کدها را در گیت‌هاب آپلود کنید
2. در Render استقرار دهید
3. ربات را تست کنید

## 📝 تنظیمات

متغیرهای محیطی را در Render تنظیم کنید:

- `BOT_TOKEN`: توکن ربات تلگرام
- `SUBSCRIPTION_PRICE`: قیمت اشتراک
- `SUPPORT_ID`: آیدی پشتیبانی
- `CHANNEL_ID`: آیدی کانال خصوصی
- `ADMIN_ID`: آیدی عددی ادمین

## 📊 دستورات

- `/start` - شروع کار
- `/backtest` - اجرای بک‌تست (فقط ادمین)

## ⚠️ توجه

این ربات صرفاً جنبه اطلاع‌رسانی دارد و مسئولیتی در قبال معاملات نمی‌پذیرد.
